# Demo media credits

Stand-in photos, portraits and clips used by `npm run db:seed:demo` and `npm run db:seed:e2e`
(through `demo-media/index.js`). Everything is openly licensed. Files were resized, cropped
or trimmed for the app. Replace them with Ladli Foundation's own media when it is available.

The people in the portraits are not the volunteers named in the seed data. The names are fictional.
